    Cybersecurity Insights

    Learning Components Before - Capture The Flag

    Use this page as a beginner guide for the tools, devices, and industrial protocols used inside the Phygital Lab hackathon rooms.

    Learning Path

    From model to attack surface

    Students first learn what the physical device is, then identify its protocol, inspect traffic, test safe lab commands, and finally document how to defend it.

    Core Devices

    PLC

    A Programmable Logic Controller runs logic for machines, pumps, gates, HVAC, traffic lights, and other physical processes. In the lab, PLC exposure helps students understand why OT networks need strong segmentation.

    Core Devices

    Raspberry Pi

    A small Linux computer used as a gateway, sensor node, dashboard host, or automation bridge. It is useful for learning because students can see how software connects physical sensors to network services.

    Industrial Protocol

    Modbus

    Modbus is a common industrial protocol for reading and writing coils or registers. The CTF rooms use Modbus concepts to teach port discovery, register mapping, safe writes, and why unauthenticated control traffic is risky.

    Industrial Protocol

    OPC UA

    OPC UA lets clients browse industrial objects and read or write values. In airport scenarios, it explains how door and baggage systems can expose objects, attributes, and weak authentication paths.

    IoT Protocol

    MQTT

    MQTT is a lightweight publish/subscribe protocol. Students learn how topics, wildcards, publishers, subscribers, authentication, and ACLs affect sensor dashboards and false-data injection risks.

    Monitoring

    SCADA And Node-RED

    SCADA dashboards show live plant state. Node-RED is often used to connect sensors, protocols, and dashboards. These views help students compare cyber activity with real physical model behavior.

    Kali Linux

    Attacker workstation used for scanning, packet analysis, and lab-only command testing.

    Nmap

    Discovers live hosts, open ports, and service names before any deeper testing.

    Wireshark

    Captures packets so students can understand protocol traffic and payload formats.

    Metasploit

    Provides modules such as Modbus clients for controlled register read/write labs.

    Netcat

    Sends or receives raw TCP data, useful for safe lab payload delivery and testing.

    Blue Team

    Focuses on segmentation, authentication, ACLs, logging, alerting, and recovery.
