# Phygital Lab

Cyber Lancers Phygital Lab portal for smart infrastructure models, CTF exercises, admin question management, wiki link integration, FAQ, and animated domain walkthrough pages.

## Run Locally

```powershell
npm start
```

Then open:

- Site: http://localhost:5000/index.html
- Admin: http://localhost:5000/admin.html

Default admin password:

```text
cdac@admin
```

## CTF Domains

- Hospital
- Banking

- Data Center
