# Phygital Lab

Cyber Lancers Phygital Lab portal for smart infrastructure models, CTF exercises, admin question management, wiki link integration, FAQ, and animated domain walkthrough pages.

## Run Locally

```powershell
npm start
```

Then open:

- Site: http://localhost:5000/index.html
- Admin: http://localhost:5000/admin.html

Default admin password:

```text
cyberlancers@admin
```

## CTF Domains

- Airport
- Water Treatment
- Industry
- Hospital
- Banking
- Power Grid
- Toll Plaza
- Data Center
- Stock Market
- Metro
- Warehouse

Runtime CTF data is generated locally in `data/phygital_ctf.json` and is intentionally ignored by Git.

## Offline Demo Video

Place the authorized MP4 demo video here:

```text
static/videos/phygital-lab-demo.mp4
```

The Home page `Demo` button plays this local file, so it works without internet.
